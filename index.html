⚠️ Fault Codes & Safety Protections Reference
Complete error code classifications and protection bitmasks reverse-engineered from power station hardware firmware and vendor diagnostics.
Reg / Source Value / Bit Classification Behavior & Diagnostics
Reg 8 (errorCode) 78 Inverter Fault AC inverter tripped or overloaded. Solar MPPT and DC 12V/USB output remain fully operational. Reduce AC load.
Reg 8 + Reg 42 79 + 0x6000 Critical Hardware Fault Internal hardware safety lockout. Power board forces master system enable (Reg 5) to 0. Requires complete power cycle or factory reset.
Reg 8 + Reg 42 79 + 0x0000 Temp / Safety Protection Ambient thermal extreme (<0°C cold charge lockout or >55°C heat cutoff). Automatically clears once pack returns to safe operating temperature.
Reg 8 (errorCode) 136 (0x88) Normal Status Healthy operational state code routinely sent by normal units. Must NEVER be treated as a fault.
Reg 21 (ac_voltage) 15 (1.5V) Cold Freeze Protection Reported when unplugged from AC mains. Indicates cell temperature <0°C (charging disabled to prevent lithium dendrite plating).
Reg 48 (statusFlags) Bit 3 (0x0008) Inverter Switching Transient Transient AC relay state during inverter start/stop. Non-authoritative; filtered to prevent false alarms.
DC-DC Reg 7 Bit 3 / Bit 7 Undervoltage / Flameout Bit 3 = Starter battery cutoff (<12V). Bit 7 = Engine flameout vibration sensor tripped (halts auxiliary charging).
🚐 DC-DC Auxiliary Battery Charger Protocol
Profile: DC_DC-V1-0083 · wp
Reverse-engineered from the BrightEMS mobile app. Manages on-board vehicle DC-DC charging systems for camper vans, RVs, and marine dual-battery setups (Starter Battery + Alternator → Auxiliary Leisure Battery).
⚡ Dual-Battery Vehicle Power Flow
Starter / Alternator (IN)
Input Regs 0, 1, 2
Monitors alternator watts, volts, and current. Cut-off controlled via Reg 14.
DC-DC Charger Stage (wp)
Reg 6 (Temp) & Reg 7 (Faults)
Engine flameout vibration detection & thermal protection stage.
Auxiliary Battery (OUT)
Input Regs 3, 4, 5
Charging power to leisure battery. Target voltage controlled via Reg 11.
📊 Telemetry Registers (Status Bank 0x1104)
Read-Only / Broadcast
Reg Field Name Unit / Scale Description
0 inputPower Watts Starter / alternator real-time input power
1 inputVolt V ÷ 10 (0.1V) Starter battery voltage (e.g. 138 = 13.8 V)
2 inputCurrent A ÷ 10 (0.1A) Alternator current draw (e.g. 250 = 25.0 A)
3 outputPower Watts Auxiliary battery charge power
4 outputVolt V ÷ 10 (0.1V) Auxiliary battery terminal voltage (e.g. 144 = 14.4 V)
5 outputCurrent A ÷ 10 (0.1A) Auxiliary battery charging current (e.g. 300 = 30.0 A)
6 deviceTemper °C Internal heatsink & power MOSFET temperature
7 faultFlags Bitmask Bit 3 = Undervoltage Protection (8), Bit 7 = Flameout Active (128)
⚙️ Configuration Registers (Holding Bank 0x1103)
Read / Write (OpCode 0x06)
Reg Setting Name Format / Range Function
10 shutdownWaitTime Minutes Inactivity auto-shutdown idle timer
11 outputVoltSet V ÷ 10 (e.g. 146 = 14.6V) Target auxiliary battery bulk/absorption voltage ceiling
12 appControlShutdown Write 1 Remote software power shutdown command
13 flameoutProtection 0 = Off, 1 = On Engine flameout / vehicle vibration cut-off protection toggle
14 inputCutoffVoltSet V ÷ 10 (e.g. 122 = 12.2V) Starter battery low voltage cutoff to prevent draining engine battery
